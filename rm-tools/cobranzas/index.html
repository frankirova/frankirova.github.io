    Cobranzas

    Generá el archivo de deuda para Autogestión con una lectura completa y actual de ISPCube. Antes de descargarlo vas a ver una vista previa.

    No modifica ISPCube ni publica datos en Autogestión. El CSV contiene datos personales: compartilo solo con personas autorizadas.

    La generación puede demorar. Mientras se procesa, se muestra «Generando CSV…» y el botón queda deshabilitado. Si falla la validación o la consulta, no se guarda ni se descarga un CSV parcial.
